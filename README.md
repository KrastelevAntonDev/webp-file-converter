# webp-file-converter

A simple and fast Node.js tool to convert PNG/JPEG to WebP with batch processing and filename preservation.

## Features

- Batch convert PNG, JPG, and JPEG images to WebP format
- **Powered by Sharp** - modern, fast image processing library
- **Recursive folder processing** - automatically processes all subfolders
- Preserves folder structure in output directory
- Preserve original filenames
- **Adaptive quality** - automatically adjusts quality based on file size
- **Smart conversion** - uses high quality (95) for small files that grow in size
- **File size tracking** - shows size reduction for each file and total savings
- **Never makes files bigger** - falls back to original format if WebP is larger
- TypeScript support with full type safety
- Fast and efficient processing

## Installation

```powershell
pnpm install
```

## Usage

### Development (direct TypeScript execution)

```powershell
pnpm dev
```

### Production (compile and run)

```powershell
# Build the project
pnpm build

# Run the compiled JavaScript
pnpm start
```

### Type checking

```powershell
pnpm typecheck
```

## Project Structure

- `index.ts` - Main TypeScript source file
- `dist/` - Compiled JavaScript output (generated by `pnpm build`)
- **`input/`** - **📥 Place your PNG/JPG/JPEG images here** (supports nested folders)
- **`output/`** - **📤 Converted WebP images will be saved here** (auto-created with same folder structure)
- `tsconfig.json` - TypeScript configuration

> **Note:** `input/` and `output/` folders are in `.gitignore` and won't be committed to the repository.

## Technology

Uses **[Sharp](https://sharp.pixelplumbing.com/)** - high-performance Node.js image processing library built on libvips. Sharp provides:
- Better compression than webp-converter
- Adaptive quality settings
- Advanced WebP encoding options (effort, smartSubsample)
- Automatic fallback to near-lossless for problematic files

## How It Works

### Step-by-step:

1. **📥 Add images** - Place your PNG/JPG/JPEG images in the `input/` folder
   - You can organize them in subfolders (e.g., `input/photos/vacation/`, `input/icons/`)
   - All subfolders will be processed automatically

2. **▶️ Run conversion** - Execute `pnpm dev` or `pnpm start`

3. **📤 Get results** - Find converted WebP images in the `output/` folder
   - Same folder structure as `input/`
   - Example: `input/photos/pic.png` → `output/photos/pic.webp`

### What happens during conversion:

- ✅ Recursively scans all subfolders in `input/`
- ✅ Creates matching folder structure in `output/`
- ✅ Converts only image files (`.png`, `.jpg`, `.jpeg`)
- ✅ Shows original size → new size for each file
- ✅ Calculates and displays size savings (KB or MB)
- ✅ Reports total space saved at the end

### Example output:

```
📦 Найдено файлов: 3

✔ photo.png → photo.webp | 2.45 MB → 1.12 MB | Сэкономлено: 1.33 MB (54.3%) [Q:75]
✔ icons/logo.png → icons/logo.webp | 8.54 KB → 7.23 KB | Сэкономлено: 1.31 KB (15.3%) [Q:90]
✔ bg/hero.jpg → bg/hero.webp | 178.50 KB → 92.45 KB | Сэкономлено: 86.05 KB (48.2%) [Q:80]

🎉 Готово! Обработка завершена.
✅ Конвертировано в WebP: 3
💾 Всего сэкономлено: 1.42 MB
```

> **Note:** `[Q:XX]` shows the quality level used (75-95). Small files automatically use higher quality.
